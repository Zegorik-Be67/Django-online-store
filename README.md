# Django Online Store

## Установка
1. Склонируйте репозиторий
2. Создайте виртуальное окружение: 'python -m venv .venv'
3. Активируйте его '.venv\Script\activate'
4. Установите зависимостей: 'pip install -r requirements.txt'
5. Установите PostgreSQL и создайте базу 'online_store'
6. Настройте 'setting.py'
7. Выполните миграции: 'python manage.py migrate'
8. Запустите 'python manage.py runserver'
